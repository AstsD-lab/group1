# Практикум группы 1 Свой или чужой

## Задача

Проверить, почему модель может показывать высокую точность на похожих кадрах, но хуже распознавать новые физические объекты. Писать модель с нуля не требуется: нужно запускать готовый эксперимент, менять по одному параметру и объяснять результат.

## Запуск

```bash
python3 -m pip install -r requirements.txt
jupyter lab
```
Необходимо исследовать работу системы распознавания «свой или чужой» и определить, как параметры генерации данных влияют на качество модели.

Сначала запустите исходную конфигурацию без изменений и зафиксируйте:

исходные параметры;

accuracy при случайном разделении;

accuracy при разделении по физическим объектам;

recall класса «чужой»;

количество общих физических объектов между обучающей и проверочной выборками.

После этого изучите параметры в начале ноутбука. Определите, за что отвечает каждый параметр, и сформулируйте гипотезы о его влиянии на результат.

Дальнейшие значения параметров вы выбираете самостоятельно.

Правило эксперимента: за один запуск изменяется только один параметр. Перед запуском запишите, какой результат ожидаете получить. После запуска запишите фактический результат и объясните различие.

Необходимо определить:

как количество разных физических объектов влияет на качество;

как количество похожих кадров одного объекта влияет на качество;

как качество изображений влияет на accuracy и recall;

почему два способа разделения данных дают разные результаты;

какие параметры влияют на результат сильнее остальных.

На выходе требуется:

таблица минимум из четырёх запусков;

старое и новое значение изменённого параметра;

метрики каждого запуска;

один основной график или матрица ошибок;

выявленные зависимости;

объяснение завышенного результата при случайном разделении;

вывод о том, какие реальные данные необходимо собирать;

предложение следующего эксперимента.

Оценивается не максимальная точность, а логика эксперимента, найденные зависимости и обоснованность выводов.

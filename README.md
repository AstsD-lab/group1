# Практикум группы 1 Свой или чужой

## Задача

Проверить, почему модель может показывать высокую точность на похожих кадрах, но хуже распознавать новые физические объекты. Писать модель с нуля не требуется: нужно запускать готовый эксперимент, менять по одному параметру и объяснять результат.

## Запуск

```bash
python3 -m pip install -r requirements.txt
jupyter lab
```

Откройте `practicum.ipynb` и выполните **Kernel → Restart Kernel and Run All Cells**. Результаты каждого запуска появятся в отдельной папке внутри `outputs_images`.

## Что фиксировать после каждого запуска

| Запуск | OBJECTS_PER_CLASS | FRAMES_PER_OBJECT | NOISE_LEVEL | Accuracy случайная | Accuracy по объектам | Recall чужого | Пересечение объектов |
|---|---:|---:|---:|---:|---:|---:|---:|
| Исходный | 10 | 14 | 12 | | | | |
| Больше кадров | 10 | 40 | 12 | | | | |
| Больше объектов | 25 | 14 | 12 | | | | |
| Больше шума | 10 | 14 | 30 | | | | |

За один запуск меняйте только один параметр. После изменения параметров заново выполняйте весь ноутбук.

## Последовательность работы

1. Запустите исходный вариант без изменений.
2. Откройте `examples.png`, `metrics.csv`, `confusion_matrices.png` и `errors.png`.
3. Сравните случайное разделение кадров и разделение по физическим объектам.
4. Установите `FRAMES_PER_OBJECT = 40`. Проверьте, помогли ли дополнительные кадры распознавать новые объекты.
5. Верните `FRAMES_PER_OBJECT = 14`, установите `OBJECTS_PER_CLASS = 25`. Сравните эффект от новых физических объектов.
6. Верните `OBJECTS_PER_CLASS = 10`, установите `NOISE_LEVEL = 30`. Проверьте устойчивость к шуму.
7. Сформулируйте итоговый вывод и предложите, какие реальные изображения нужно собрать.

## Ожидаемый исходный результат

Значения могут немного меняться, но при `SEED = 42` ориентир такой:

- случайное разделение: accuracy около `0.83`, recall чужого около `0.81`;
- разделение по физическим объектам: accuracy около `0.67`, recall чужого около `0.64`;
- пересечение объектов при случайном разделении: больше нуля;
- пересечение объектов при разделении по объектам: строго ноль.

## Правильные выводы

- Случайное разделение похожих кадров завышает качество.
- Проверять систему нужно на новых физических объектах.
- Разнообразие объектов обычно полезнее большого количества кадров тех же объектов.
- Для опасного класса «чужой» важно смотреть не только accuracy, но и recall.
- Высокая метрика не доказывает, что модель изучила нужный признак: она могла запомнить фон.
